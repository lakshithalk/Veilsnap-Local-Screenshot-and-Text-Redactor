# Changelog

All notable changes to VeilSnap are recorded here.

## 0.1.0 — 2026-08-17

- Added the local screenshot redaction desk with solid and blur regions.
- Added pasted-text replacement using exact comma-separated terms.
- Added local PNG and plain-text export.
- Added an evidence-led product page with transparent capability boundaries and FAQ.
- Documented that the initial release does not claim to strip image metadata or automatically detect secrets.
